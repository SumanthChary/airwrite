# AirWrite ✍️

AirWrite is a lightweight, high-performance web application built with [TanStack Start](https://tanstack.com/start?utm_source=gemini) and [TypeScript](https://www.typescriptlang.org/?utm_source=gemini). It provides an intuitive, distraction-free interface for seamless writing and content creation.

---

## ⚡ Tech Stack

* **Framework:** [TanStack Start](https://tanstack.com/start?utm_source=gemini) (React)
* **Language:** [TypeScript](https://www.typescriptlang.org/?utm_source=gemini)
* **Build Tool & Server:** [Vite](https://vitejs.dev/?utm_source=gemini) + [Bun](https://bun.sh/?utm_source=gemini)
* **Formatting & Linting:** [ESLint](https://eslint.org/?utm_source=gemini) + [Prettier](https://prettier.io/?utm_source=gemini)

---

## 🚀 Getting Started

### Prerequisites

Ensure you have [Bun](https://bun.sh/?utm_source=gemini) installed on your system.

```bash
curl -fsSL https://bun.sh/install | bash

```

### Installation

1. Clone the repository:
```bash
git clone https://github.com/SumanthChary/airwrite.git
cd airwrite

```


2. Install dependencies:
```bash
bun install

```



### Development

Start the local development server:

```bash
bun dev

```

Open `http://localhost:3000` in your browser to view the application.

| Command | Description |
